CrossCheckMonadBlitz20261017

CrossCheck：双模型审阅报告、Monad 测试网存证和浏览器独立复核。

这份公开演示是什么

公开页面回放三份固定样例。样例报告已经真实写入 Monad 测试网，浏览器可以直接读取 RPC 并核对完整报告指纹。修改模型理由后，核验会失败。

样例没有调用真实模型 API，也不证明内容真假。页面显著显示这个边界，不伪造厂商签名或实时审核。

完整产品包含什么

四页前端、Express 后端、并行模型适配器、SSE 进度、持久报告、授权发证合约、完整 JSON 导出及浏览器复核。真实 API 模式需要在服务器配置两家 Key 和实际可调用的模型 ID；当前尚未配置和实测。

为什么有完整报告指纹

报告包含原文、请求与返回模型标识、两份判断、理由、时间及规则版本。对象键递归排序，数组保序，原文不去空白；模型理由也参与 Keccak-256。指定合约只接受授权发证钱包，浏览器核对交易回执、事件、发证地址和指纹。

如何复查

回到演示页，选择样例，点击核验原始报告。确认成功后，再点击修改模型理由并核验。也可以下载 JSON，在自己的浏览器导入。导入文件仅本地处理，不上传。
